# Smoker（燻製器 MOD）

燻製器を組み立てて、魚・肉・チーズを燻製にする B42 用 MOD。燻製は日持ちが長く（肉・魚 14日／チーズ 30日で傷み始める）、そのまま食べられる。普通に焼いた肉や魚より気分が良くなる（悲しみ −10・退屈 −10、チーズは悲しみ −15・退屈 −10）。スープや炒め物などの具にも使える。

## 遊び方

1. 組み立てメニュー（Farming）で「燻製器」を作る。材料: 小さい金属板 2、針金 4 回分（中の網 2 枚）、ネジ 4、ハンマーとドライバー（道具は減らない）
2. 生の肉や魚に塩（塩・味付け塩のどちらでも、1回分）をして「燻製の仕込み」を作る。チーズは塩なしで仕込む
3. 燻製器に仕込みを入れ、焚き火と同じように燃料を入れて火をつける（容量 7）
4. 火が燃えている間だけ燻製が進み、約 11 時間半（チーズは 4 時間）で燻製に変わる。火が消えると止まり、つけ直すと続きから進む。燻製になった後も火のついた燻製器に 2 時間以上置くと焦げる（燃料満タン 12 時間で 1 回分なら焦げない。続けて次を燻すときは先に取り出す。チーズは燃料を 4〜6 時間分にする）。燃料の目安（本体の `camping_fuel.lua`）: 丸太 1 本 6 時間、板 1 枚 2 時間、炭 1 個 30 分。12 時間なら丸太 2 本。燻製器には燃料を 12 時間分まで入れられる（普通の焚き火はサンドボックス設定の上限、標準 8 時間）ので、最初に入れておけば途中で足さなくてよい
5. 肉や魚の仕込みを燻製器以外（オーブン・焚き火など）で加熱すると、元の肉と同じ時間で普通に焼けた肉になる。チーズの仕込みは本体のチーズと同じく加熱できない

| 仕込みの材料 | できるもの |
|---|---|
| 魚の切身 | 魚の切身の燻製 |
| さばけない小魚（丸ごと） | 小魚の燻製 |
| 豚肉・豚肉の切り身・牛肉・ステーキ・鶏（もも／切り身／手羽）・ターキー（切り身／脚／手羽）・骨付ラム・鹿肉・ウサギ肉・げっ歯類の肉・小鳥の肉 | それぞれの燻製 |
| チーズ（プロセスチーズはスライスの包装ごと燻すように見えるので対象外） | スモークチーズ |

仕込みは生肉と同じ扱い（加熱せずに食べると危険）で、生肉より少しだけ日持ちする（4日）。腐った材料では仕込めない（B42 のレシピの標準動作）。

## 小魚のコーンミール揚げ

アメリカ南部風に、さばけない小魚を丸ごと揚げる。

1. 「小魚にコーンミールの衣を付ける」（台の上・料理）: さばけない小魚 1 匹、コーンミール 2 回分、卵 1 個、ニンニク（生・粉・野生・乾燥のどれか）1 回分、油（植物油・オリーブ油・ラード）3 回分 → 衣を付けた小魚（生。餌魚は不可）
2. フライパンなどで加熱すると 15 分で「小魚のコーンミール揚げ」になる（パン → トーストと同じ `ReplaceOnCooked`）。そのまま火にかけておくと焦げる。温かいうちに食べると気分が良くなる
3. 絵は `tools/draw_fish.py` が描いた自前の絵。アイコン 2 種と、本体の小魚の 3D 模型（`Fish_Bluegill_Sunfish`）に貼る衣の模様（`media/scripts/Smoker_models.txt` で本体の模型に自前の模様を組み合わせている）

## 仕組みのメモ

- ゲームは置いてある物の絵の名前から設置物の種類を判断する。そのため、本体の絵（グリルや物干し台）をそのまま使うと、本体の物と取り違えられる。MOD 専用の絵 `smoker_01_0` を `mod.info` の `pack=` / `tiledef=`（番号 4217。絵のまとまりの番号は 1〜512）で読み込ませている
- 燻製器の火の機能は、絵の設定 `IsoType = IsoFireplace` から来る（本体の石のかまども同じ作り）。入れ物の種類は `container = smoker` にして、入れ物の名前（`IGUI_ContainerTitle_smoker`）とボタンのアイコンを自前にしている。`campfire` のままだと「焚き火」と表示されて紛らわしいため。火の熱は入れ物の種類ではなく持ち主が `IsoFireplace` かどうかで決まるので、種類を変えても影響しない
- 煙は `make_tile.py` がプログラムで描いた白い煙 `SmokerSmoke_01_0`〜`29`（30 コマ、自前の絵）を `smoker.pack` に入れ、本体が焚き火に炎を付けるのと同じ `AttachAnim` で燻製器に重ねている。本体の火事の煙 `Smoke_01` は黒っぽく、色の掛け合わせでは白くできないため。煙の色・濃さは `make_tile.py` の `SMOKE_*`、位置・速さは `Smoker_Client.lua` の `SMOKE_*`。位置は燻製器の本番の絵ができてから合わせる
- 入れ物ボタンのアイコンは `make_tile.py` が燻製器の絵を 34×34（本体の入れ物アイコンの大きさ）に収めた `smoker_icon`
- 燻製は本体の加熱の仕組みを使わず、`Smoker_Smoke.lua`（サーバー側、一人プレイではゲーム本体）が 1 ゲーム分ごとに数える。燻製器は `MapObjects.OnNewWithSprite` / `OnLoadWithSprite`（本体の肉吊りフックと同じ）で見つけて覚えておく。中の仕込みは毎回、加熱の進み（`setCookingTime(0)`）を戻すので焚き火の熱では焼けず、火がついている間（`isLit()`）の時間を仕込みの `modData.smokerMinutes` にためる。燃料満タン（12 時間）で必ず終わるよう、必要時間は 690 分
- 最初は `ReplaceOnCooked` で燻製に変えていたが、本体の `Food.update` は `ReplaceOnCooked` があると `OnCooked` を呼ばないため、どこで加熱しても燻製になっていた（焚き火でチーズが燻製になった）
- 燻製器以外で焼けたときは `OnCooked = SmokerRecipe.onCooked` が呼ばれ、次の画面更新で本体の普通の肉（焼けた状態）に差し替える。焼き時間・焦げる時間は元の生肉の値をそのまま使う
- アイコンは本体のアイコンをそのまま指定し、`ColorRed/Green/Blue` で色を掛け合わせて表示させている（本体の溶けたアイスと同じ仕組み）。燻製は茶色、仕込みは少しくすんだ色。画像ファイルは同梱しない。色は `make_items.py` の `TINT_SMOKED` / `TINT_CURED`
- 燃料の上限はサンドボックス設定 `MaximumFireFuelHours`（標準 8 時間）で、Lua の `getCampingFuelMax()` だけで確かめている（Java の `IsoFireplace.addFuel` は上限で切らない）。`Smoker_Fuel.lua` は、燃料を足すメニューと燃料を足す動作が燻製器を相手にしている間だけ、この関数が 12 時間（`SmokerRecipe.FUEL_MAX_HOURS`）を返すようにしている
- 本体には放置で燃料を使って加工する仕組みとして `FurnaceLogic`（炉）も Java 側にあるが、本体のどこでも使われておらず、入れる画面がないので使っていない

## 自動テスト（デバッグモード・1人プレイ）

デバッグモードで燻製器を右クリック →「Smoker: run tests」。`media/lua/client/Smoker_Tests.lua` が次を確かめ、`console.txt` に `[SmokerTest] PASS/FAIL` で出す（最後に「何件中何件成功」をキャラクターがしゃべる）。

- アイテム・レシピ・名前の翻訳・自前の絵が読み込まれているか
- 小魚の判定（小さい魚は可、大きい魚・餌魚は不可、コーンミールや卵などは判定の対象外）
- 燻製の流れを時間を与えて再現: 火が消えていると進まない、チーズ 4 時間・肉 11 時間半ちょうどで燻製、焚き火の熱で焼けない、燻製後 2 時間で焦げる
- 燃料の上限（燻製器だけ 12 時間）
- 燻製器以外で焼けた仕込みが普通の焼けた肉になる

マルチ用のテストは `MP_TESTPLAN.md` の「自動テスト」（run・watch・outside cooking watch の 3 つ。結果は `python tools\check_logs.py` がまとめる）。ゲームを起動せずに確かめられるところは `python tools\check_mod.py`（本体にない名前の参照、翻訳の抜け、ほかの MOD との絵の番号や名前の重なり）。燻製器の中に仕込みや燻製が入っていると、燻製のテストは飛ばす（与えた時間が中身にもかかるため）。テスト用に出したアイテムは最後に消す。見た目（煙・アイコン・模型）とレシピ画面からの作成は手で確認する。

## 未確認（ゲーム内で要確認）

マルチでの確認の状況は `MP_TESTPLAN.md` の「今の状態と残り」。1 人プレイ・マルチの自動テストで確かめ済み: 燻製器の登録（組み立て時・読み込み時）、11 時間半で燻製に変わること、燻製器の熱で焼けないこと、燃料の上限（サーバー側の値）、差し替えが開始した本人に届くこと。

- 煙の位置（蓋のつまみから出るか）、濃さ。マルチで他の人にも見えるか（点け消しの同期は MP test に入れた）
- 入れ物の名前が「燻製器」、アイコンが燻製器の絵になるか（種類を変えたので、作り直した燻製器で確認）
- オーブンなどで本当に焼いた仕込みが普通の焼けた肉になるか（`[Smoker] onCooked`。マルチは「MP outside cooking watch」で確かめる）
- 小魚の判定（`OnTest`）が仕込みレシピで効くか
- 燻製器に 8 時間を超えて燃料を入れる操作（マルチで右クリック・入れ物画面の両方）
- 変化がもう 1 人のプレイヤーにも届くか（今日の自動テストは 1 人しか答えていない）
- `console.txt` の `[Smoker]` の行は確認用で、デバッグモードのときだけ出る（`tools/check_logs.py` が読む）
